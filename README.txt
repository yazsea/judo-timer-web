<<< 起 動 方 法 >>>
● iPhoneでホーム画面追加、Androidでインストール。←こちらを推奨
● 単体利用: timer_web_b1.74.html または index.html をブラウザで開いて、ボタン以外の場所をタップして全画面にする。（この場合、iPhoneでは全画面に出来ません）

==== iPhoneでのホーム画面への追加手順 ====
・Safariでサイトを開く
・共有ボタンをタップ：画面下部（または上部）にある「共有」アイコン（四角から矢印が出ているマーク）を押します。
・ホーム画面に追加を選ぶ：メニューを下にスクロールし、「ホーム画面に追加」をタップします。
・名前を確認して追加：右上の「追加」を押すと、iPhoneのホーム画面にアイコンが作成されます。
・アンインストールはホームから削除

==== Androidでのインストール方法 ====
・Google Chrome サイトを開く。
・画面右上（またはメニュー内）の 「︙」（縦の三点リーダー） アイコンをタップする。
・メニューから 「アプリをインストール」 または 「ホーム画面に追加」 を選択する
・確認画面で 「インストール」 または 「追加」 をタップすると通常のアプリと同じ扱いができる。
・アンインストールは設定→アプリからアンインストール


<<< 使 用 方 法 >>>
オールリセットは画面下部『リセット』をトリプルタップしてください。
抑込リセットは、どちらのボタンでもリセットできます。

柔道審判経験者なら説明なしの初見で使えると思います。



※※ 注 意 ※※
・ ホームページとして機能させる場合、設定画面を出した後、タイマー画面に戻ったときにページの再読み込みをします。
　とにかく、挙動がおかしくなった場合は再読み込みしてみてください。

・ロングタップでのカウント変更は、 わざと『試合タイマーの秒』のみを対象としています。
　他は変更のカウント数が少ないのでポチポチしてください。

・有効のカウントは９までです。実際の経験では最大で５つでした。

・『そのまま』のジャッジがあった場合のため抑込のタイマーは一時停止とリセットを分けています。
　ここは迷ったのですが『そのまま』を宣告した経験もあるため、この仕様としました。
