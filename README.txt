起動方法
1,単体利用: timer_web_b1.63.html または index.html をブラウザで開く
2,ボタン以外の場所をタップして全画面にする

オールリセットは画面下部『リセット』をトリプルタップしてください
抑込リセットは、最後の抑込の色でリセットしてください

おせっかい機能
抑込時、解けたの秒数判定して自動で有効、技ありを振ります。



※※ 注 意 ※※
・ 設定画面を出した後、タイマー画面に戻ったときにページの再読み込みをします。
　挙動がおかしくなった場合は再読み込みしてみてください。

・ロングタップでのカウント変更は、 わざと『試合タイマーの秒』のみを対象としています。
　他は変更のカウントが少ないのでポチポチしてください。

・有効のカウントは９までです。実際の経験では最大で５つでした。

・『そのまま』のジャッジがあった場合のため抑込のタイマーは一時停止とリセットを分けています。
　ここは迷ったのですが『そのまま』を宣告した経験もあるため、この仕様としました。
